# v0.2 · GPU_설계_ERD 구현 점검

점검일: 2026-11-17 (KST), 2차 보완. 전체 요구사항 구현 완료 상태가 아닙니다.

## 주요 상태

- ERD 구조: **운영 DB 대조 보완** — PostgreSQL의 ERD 17개 테이블·154개 컬럼 일치. 스키마 전체 FK 32개 확인. 관측-오퍼·상품·대상 및 근거/환산/정정 연결 검사 7항목 모두 오류 0건. 노션 개별 17개 테이블 페이지의 모든 서술을 전수 검사한 것은 아님.
- 환율·금리: **실조회·적재·표시 확인** — 한국수출입은행 AP01·AP02 실제 인증·조회·PostgreSQL 적재 확인. 2026-11-17 USD/KRW 1,335원, 금리 41개. 매일 스케줄 미설정. 현재 기준 환산이며 과거 당시 환율과 다름.
- 원화·사용자 환율: **상세 화면 오류 수정** — 관측 당시 환율 이력과 최신 자동 환율을 구분. 상세 화면에도 현재 환율·기준일·출처와 원화 환산 표시. 사용자 환율은 저장하지 않음.
- 계약 비교: **기존 유지·용어 보완** — 스팟 가격 차이·장기약정 할인율 유지. 미확인 구성은 참고 비교.
- 과거 관측: **이력 범위·시간 기준 보완** — 현재가·공식 과거 카탈로그·SQL 백업별 기록/오퍼/날짜 수와 기간 표시. Azure 현재가를 장기 이력으로 오해하지 않도록 안내. KST 기간 필터·차트/목록 적용. 점 그래프 유지. 당시 환율 효과는 자료 부족.
- 원가·IRR: **브라우저 계산 추가** — CRF·마진/가산율·현금흐름·목표 IRR 가격. 경쟁사 상한 검증은 미완료.
- 동일 조건 집계: **판정·화면 구현 / 유효 표본 미확보** — 동일 조건·지역 제외·참고 비교, 조건 집단별 집계, 제외 사유, 사업자 대표가격·오퍼 통계와 상품/오퍼/사업자/관측 수 추가. 현재 엄격 집단 0개. 대표가격=사업자별 최저 실효 단가를 잠정 적용하며 팀 확정 필요.
- 매일 수집·운영 평가: **운영 조회 보완 / 자동화 미완료** — 407개 대상의 공개/처리 상태·마지막 전체 범위 성공와 저장 알림 2건 표시. 매일 스케줄·재시도·신규 이상탐지·정답표 평가는 미연결.
- 가격 질의 Agent: **미연결** — 모델·도구·조건해석·후속질문 및 민감정보 필터 필요.

## 적용 기준과 남은 제한

- 노션 ERD 본문, 테이블 목록, 기능별 데이터 연결, 결정할 사항·제약을 재확인했습니다. 개별 테이블 17개 페이지의 모든 설명을 전수 확인했다는 뜻은 아닙니다.
- 원본 ERD SQL과 운영 PostgreSQL 컬럼을 대조하고 실제 연결 무결성을 별도 검사했습니다. 결과는 `docs/review_20261117/live_integrity.json`입니다.
- 한국수출입은행 환율·금리는 사용자 요청에 따른 출처 선택입니다. 매일 자동 수집은 아직 없습니다.
- 점 그래프는 사용자 요청을 우선합니다. 현재가의 적용 시작일은 과거 관측일로 쓰지 않습니다.
- 표준 구성·사업자 대표가격 선정 방식은 팀 확정 필요입니다. 사업자별 최저 실효 단가 1개를 잠정 대표가격으로 명시했습니다.
- 현재 동일 조건/지역 제외 유효 집단 모두 0개입니다. 화면과 계산 기능을 만들었다는 사실이 비교 가능한 원본 데이터를 확보했다는 뜻은 아닙니다.
- 가격 기록 11,613건을 보존했습니다. 이번 변경으로 새 GPU 가격을 수집하거나 원본 DB를 덮어쓰지 않았습니다.
- 자연어 Agent, 매일 수집/재시도, 공식 사양 보완, 수기 정답표 평가, IRR 시장 상한 검증은 남아 있습니다.
