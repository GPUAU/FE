자료 해석

현재 실행본은 수집 시점의 스냅샷이며 자동 예약 수집은 설치하지 않았습니다. 공식 일치는 동일 SKU·표기 지역·요금 방식의 관측 가격 대조이며, 현재 가용성과 서비스 동등성을 뜻하지 않습니다.

기본 집계 자료는 GPU Ledger와 GPU Economy의 CC BY 4.0 데이터입니다. 출처를 유지하고 선별·환산했습니다. 공식 관측과 제공받은 과거 자료에는 이 라이선스를 일괄 적용하지 않습니다.

과거 자료는 별도 보관함에서 확인합니다. 과거 사업자 구성이 다르고, 첨부 증거 파일이 없어 독립 재검증하지 못한 이력이 포함됩니다. 자료 공백은 채우지 않았습니다.
