# 시장 뉴스 알림: 구현 상태와 후속 방향

## 구현 완료
- 관심 사업자 페이지의 알림 UI 시안
- 사업자, GPU, 가격 하락률 조건과 읽음 상태의 브라우저 저장
- 가격 변동·신상품·공급 동향 필터와 상세 보기
- 모든 가격·뉴스는 가상 예시이며 실제 수집·발송과 연결되지 않음

## 논의한 후속 방향 (미구현)
GPUaaS 사업자의 자산가치와 수익성을 판단할 근거를 제공한다.
1. GPU 내용연수·감가상각 정책과 자산 손상 관련 기사·공시
2. 세대별 GPU 임대료, 구형 GPU 계약 갱신·수요 관련 정보
3. 엔비디아 판매가격·마진 변화와 그 이유
4. 액체냉각 도입, 데이터센터 전환·신형 GPU 실제 가동

가격 변화 사실, 관련 동향, 확인된 인과관계를 분리한다.
임대료·중고 거래가격·회계상 장부가치·담보평가액은 서로 다른 지표다.
영상의 수치와 가설은 검증 없이 잔존가치나 IRR 계산에 자동 반영하지 않는다.
공식 발표·공시를 우선하고 출처·발표일·관련 사업자·GPU 모델을 함께 표시한다.
