# 기존 화면 신뢰성 개선 — 2026-11-19

Agent 구현은 다음 작업으로 보류하고, 실행 중인 화면의 집계·원가·IRR·품질 조회를 보완했습니다.

## 변경

- 홈과 조건별 비교는 동일한 /api/erd/comparison 판정과 공통 집계 함수를 사용합니다. 서버가 승인한 하나의 조건 집단 안에서 사업자별 최저 1개를 선택합니다. 참고가격, 미래/누락 시각, 유효하지 않은 가격은 집계에서 제외합니다. 참고 목록은 보존합니다.
- 홈의 모델·계약·사업자·리전·검색어를 조건별 비교로 전달합니다. 선택 목록의 최신 관측일을 표시하며, 가격이 없을 때 전체 데이터 날짜를 해당 모델의 관측일로 표시하지 않습니다.
- 홈 재조회는 Signature와 market 캐시를 함께 초기화합니다.
- 원가식 COST-CRF-RESIDUAL-1: 연 자본회수분 = (초기 투자금 − 잔존가치/(1+r)^n) × CRF. 명시적 0%만 무이자로 처리합니다.
- 취득비, 잔존가치, 자본비용률 등 필수값 누락은 차단합니다. 잔존가치 투자금 초과, 자본비용률 100% 초과, 음수·100% 이상 매출 마진을 거부합니다.
- 전기료 별도 계산/운영비 포함/미확인을 구분하고 이중 계상을 차단합니다. 월별 달력 시간과 연간 고정 8,760시간을 구분합니다. 가동률은 판매시간에만 곱합니다.
- 원가·IRR 입력 변경 시 이전 결과를 제거하고 재계산 필요를 표시합니다. 원가 수정 시 전달 가능한 계산도 무효화합니다.
- 원가→IRR 적용 버튼은 덮어쓸 필드를 사전 안내하고 투자금·기간·잔존가치·GPU 수·가동률·가격·현금 운영비를 전달합니다. 기존 목표 IRR은 유지합니다. 월 가정 전달은 연간 고정 적용이며 전기료를 연 8,760시간으로 환산합니다.
- 현재 IRR 기준가격은 연속 해입니다. 시장 상한/격자 탐색/추천 범위가 구현된 것으로 표현하지 않습니다.
- 품질 화면의 상태·수집 대상·Spring 경고를 독립적으로 조회하고 실패 영역만 재시도합니다. 누락된 과거 점검 파일을 요구하는 API를 더 이상 호출하지 않습니다. 과거 점검 문서는 실시간 검증 결과와 구분합니다.
- 원가/IRR 화면에서 실제 계산에 적용되지 않던 기존 표시 통화 메뉴를 숨겼습니다. 비용별 USD/KRW 선택과 환율 입력은 유지합니다.

## 검증

```sh
node --test tests/*.test.mjs
```

36개 테스트 통과(기존 21개 + 추가 15개). 수정 JavaScript 8개 문법 검사 통과.

가상 입력 검산:
- 투자 400,000 USD, 잔존 100,000 USD, 자본비용률 5%, 5년, 연 운영비 34,000 USD, 8 GPU, 가동률 70% → 연간 원가 약 2.207527 USD/GPU·시간.
- 2027-02, IT 10kW, PUE 1.2, 전기단가 100원/kWh, 가정 환율 1,000원/USD → 672시간, 전기료 806.40 USD. 위 운영비에 합산하여 IRR로 전달한 연 현금 운영비 44,512 USD.
- 1년 투자 100, 연 유입 100, 잔존 10 → IRR 10% 독립 검산.

실제 브라우저 확인:
- 홈과 비교 모두 현재 동일 조건 표본 0건을 집계 불가로 표시.
- 홈 검색어를 비교 화면에 전달하고 홈 재조회 정상 수행.
- 원가 계산·필수 자본비용률 누락 차단·월 전기료 계산·IRR 전달 정상.
- IRR 계산 후 판매가격을 변경하면 이전 IRR 결과가 제거됨.
- 품질 화면 3개 영역 조회 완료, 브라우저 오류 로그 없음.
- 테스트에 사용한 가정값은 새로고침으로 초기화했습니다.

## 남은 범위

자동 환율의 실제 수집·DB 적재, 공식 사양 근거 확보, 자동 수집 스케줄, 몬테카를로 예측, 가동률 시나리오 비교, 시장/예측과 연결된 추천 범위 및 Agent는 이번 수정에 포함하지 않았습니다. 전체 명세 완료본이 아닙니다. 원가·IRR은 아직 브라우저 계산이며 서버 공통 모듈로 이전하지 않았습니다. 실제 은행 인증·모바일 브라우저·동시 사용자·외부 수집 운영은 이번에 검증하지 않았습니다.

기존 백엔드 /api/erd/requirements의 누락 파일 문제 자체는 변경하지 않았습니다. FE 품질 화면이 해당 호출에 의존하지 않도록 수정했습니다. 다른 저장소와 백엔드 코드는 수정하지 않았습니다.


## 수집 가격 범위 표시 보완

홈의 큰 숫자는 선택 목록의 수집 가격 최저·중앙·최고를 참고용으로 표시합니다. 사업자별 대표값 축약을 적용하지 않으며, 서로 다른 리전·구성·수집일 및 과거 수집 자료가 포함될 수 있습니다. 수집일 범위, 시각 미확인 수, 단일 사업자 여부를 함께 표시합니다. 동일 조건 대표가격은 별도 영역에서 기존 엄격한 기준을 유지하고 제외 사유를 펼쳐 볼 수 있습니다. 유효한 가격이 없으면 0 대신 자료 없음으로 표시합니다.


온디맨드의 선납 방식 미확인은 비교 API의 판정입니다. 현행 비교 규칙은 약정기간만 해당 없음으로 처리하고 선납 방식을 추정하지 않습니다. 계약 유형별 해당 없음 처리와 원천 데이터 매핑은 백엔드·명세 합의가 필요한 후속 항목으로 남기고 FE에서 판정을 우회하지 않았습니다.
