# GPU 12개월 시장가격 범위 시연

## 목적

동일 조건의 가격 이력에서 미래 12개월의 가격 경로를 생성하고, 월별 중앙값과 P10~P90 범위를 보여준다.
원가·제안가·IRR 화면이 아니며 실제 시장가격을 맞히는 성능이 검증되었다는 주장을 하지 않는다.

## 발표 설명

> 이 기능은 향후 12개월 GPU 시장가격이 어느 범위로 움직일 수 있는지 보여줍니다.
> 현재는 실제 수집 기간이 충분하지 않아 직접 만든 목데이터로 시연합니다.
> 버튼을 누르면 월별 가격 변화를 분석하고, 여러 미래 경로를 생성해 중앙값과 가격 범위를 계산합니다.
> 향후 같은 GPU·사업자·리전·계약 조건의 실제 가격 이력이 충분히 쌓이면 입력 자료를 교체하고,
> 과거 구간 검증과 기준 모델 비교를 거쳐 업무에 활용할 계획입니다.

## 시연 순서

1. GPU 모델을 선택하고 오른쪽에 표시된 월별 목데이터와 입력 기간을 설명한다.
2. `12개월 시뮬레이션 실행`을 누른다. 별도 계산 서버 없이 브라우저 Web Worker가 계산한다.
3. 오른쪽의 4개 분석 단계와 실제 생성된 경로 수를 확인한다. 진행 과정을 인위적으로 지연하지 않는다.
4. 과거 목데이터와 미래 시뮬레이션 구간을 나누는 세로선을 가리킨다.
5. 중앙값 선과 P10~P90 범위를 설명한다. 이 범위는 월별 모의 가격의 중앙 80%이며, 최소~최대 또는 80% 예측 정확도가 아니다.
6. 미래 구간만 보기, 개별 경로 24개 보기, 3·6·12개월 요약, 월별 결과 CSV를 시연한다.
7. 같은 설정과 시드로 재실행하면 동일한 수치가 나온다.

## 데이터와 계산

- `scripts/generate_mc_demo.py`: 모델별 고정 난수 시드로 2025-06~2026-11의 **18개 가상 월별 가격**을 각각 생성한다. B300의 생성 시드는 20261127이다.
- 실제 사업자의 가격이나 관측 결과를 복제한 자료가 아니다. GPU 모델명은 시연 대상을 구분하는 이름이다.
- 완만한 하락, 난수 변동, 가상의 공급 이벤트를 입력 자료 생성 규칙으로 사용한다.
- 입력 형식은 `schema_version=1`, `frequency=monthly`, `unit=USD/GPU-hour`이며, 상품·사업자·리전·계약 유형·출처 구분과 가격 기준을 포함한다.
- 중복·누락 월, 음수·0·비유한 가격, 잘못된 단위는 거부한다.
- 가격의 로그 변화율을 정상 블록 부트스트랩으로 재추출한다. 평균 블록 길이 기본값은 3개월이다.
- 각 경로는 마지막 입력 가격에서 시작하고, 12개월 전체를 계산한다.
- 기본 20,000개 경로, 선택 범위 1,000~50,000개. Mulberry32 난수 생성기를 사용한다.
- 추가 가격 인하 이벤트는 기본적으로 0%다. 활성화 시 월별 지정 확률과 삼각분포 −30%/−15%/−5%를 적용한다.
- 모든 경로를 월별로 정렬하여 선형보간 분위수 P10/P25/P50/P75/P90을 구한다.
- 화면의 개별 경로 24개는 실제 생성한 첫 24개이며, 분위수는 전체 경로에서 계산한다.
- LLM이나 외부 AI API를 호출하지 않는다. 요약 문장은 실제 산출값으로 작성한다.
- 이전 Python PM 프로토타입과 동일한 난수열을 보장하지 않는다. 현금흐름·IRR은 계산하지 않는다.

## 실제 데이터 전환 조건

가격 데이터 입력 경계는 `montecarlo-core.mjs`의 `validateDataset`으로 분리했다.
핵심 계산기는 `kind=observed`와 출처 URL·수집 시각이 포함된 자료를 받을 수 있지만,
**현재 발표 화면의 로더는 목데이터 전용으로 제한되어 있고 실제 DB 연결은 구현되지 않았다.**
따라서 실제 전환에는 아래 작업이 필요하다.

1. 동일 GPU·사업자·리전·계약 조건으로 시계열을 분리한다. 서로 다른 상품을 한 가격 이력으로 합치지 않는다.
2. GPU당 시간당 USD 단가와 월별 대표값 산출 기준을 결정하고, 원본 수집 시각·근거를 보존한다.
3. 중복·결측·단위 변경·가격 구성 변경을 확인한다. 결측 월을 임의로 관측값으로 채우지 않는다.
4. 충분한 기간과 가격 변화를 확보한 후 DB/API 어댑터를 작성한다. 스팟 90일 자료를 월별 18개월 자료처럼 취급하지 않는다.
5. 발표 전용 로더 제한을 정식 데이터 흐름으로 바꾸고, 출처 배지·차트·CSV·설명도 관측 자료 기준으로 연결한다.
6. 과거 구간 백테스트, 최근 가격 유지 등 기준 모델과 비교, 구간 포함률·오차를 검토한 뒤 활용 범위를 정한다.

이력의 질과 길이가 부족한 문제는 경로 수를 늘리는 것으로 해결되지 않는다.

## 검증

`node --test tests/montecarlo-core.test.mjs`

연속 월·단위 검증, 12개월 경계, 분위수 순서, 난수 재현성, 상수 가격·고정 변화율,
이벤트 옵션, 진행 경로 수, 관측 출처 요구를 검증한다.

## GPU 모델 선택

B300·GB300·VR200·B200·H100·GB200·H200을 선택할 수 있다.
모델별 독립 난수 시드와 가상 단가·변동 가정으로 각각 18개월의 이력을 생성한다.
모든 모델의 이력은 시연용이며 실제 출시 시점, 상품 구성, 시장가격이나 성능 차이를 나타내지 않는다.
GB/VR 모델도 GPU 1장당 가상 단가이며 실제 NVL72 랙 견적을 뜻하지 않는다.

처음에는 GPU를 선택하고 실행한다. 결과 표시 후 또는 계산 중 모델을 바꾸면
기존 작업을 취소하고 선택한 모델로 다시 계산한다. 세부 설정은 유지되며 이전 결과는 지운다.
입력·결과 CSV에 선택 모델과 데이터셋 ID가 포함되고 파일명도 모델별로 달라진다.
목록 파일은 `montecarlo-demo-catalog.json`이며 기존 B300 단일 파일은 회귀 검증용으로 유지한다.

## 담당자용 계산 원리 안내

상단의 `어떻게 계산하나요?`를 누르면 네 단계 설명으로 이동한다. 선택 GPU의 이력과 월별 변화율 예시, 현재 경로 수·평균 블록 길이·시드·이벤트 가정을 표시한다. 설정을 바꾸면 설명도 갱신된다. 상세 계산식과 실행 근거는 펼쳐서 확인한다. 별도의 상단 시연 배너와 발표 대본 영역은 화면에서 제거했고 발표 대본은 이 문서에서만 제공한다.
