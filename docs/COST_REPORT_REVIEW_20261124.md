# 원가·후보가격: 멘토링 자료 반영 (2026-11-24)

- IAS 16, 43·50·51·55·56항: 중요한 구성요소별 상각, 내용연수에 걸친 체계적 배분, 내용연수/잔존가치 재검토, 유휴기간과 상각, 기술적 노후화.
  https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2022/issued/part-a/ias-16-property-plant-and-equipment.pdf?bypass=on
- NIST Handbook 135 (2020), annual-value / uniform capital recovery factor:
  https://nvlpubs.nist.gov/nistpubs/hb/2020/NIST.HB.135-2020.pdf

보고서는 1GW 분석에 IT 장비 5년, 시설 14년을 사용하고 IT 내용연수 3·5·7년의 차이를 검토한다. 제품에서는 이를 선택 가능한 예시로 제공한다. 회계·세법상 확정 내용연수나 모든 GPU의 권장 수명으로 표시하지 않는다. 별도 메모리는 제품에서 IT 자산으로 분류한다. 사용자가 보고서 예시 버튼을 누르면 IT/시설의 내용연수만 변경하며 금액·가동률·잔존가치·상태를 채우지 않는다.

보고서의 CRF 24%는 단순 5년 정액상각률 20%와 다르다. 제품은 24%를 상수로 복사하지 않고 입력 할인율로 재계산한다. 1GW 투자금, 미국 세율 21%, 소프트웨어 부가매출 10%, 임대료 $3, 전력단가는 기본값으로 이식하지 않는다. 보고서의 전기료 서술과 표 수치도 일치하지 않아 해당 총액을 재현 기준으로 사용하지 않는다. EBITDA/단순 투자금 회수기간을 IRR과 동일시하지 않는다.

## 계산 계약

자산 i의 취득비 P_i와 종료 잔존가치 S_i는 USD, 내용연수 n_i는 1~100 정수년, r은 공통 연 자본비용률이다.

- CRF(r,n) = r / (1 − (1+r)^(-n)); r=0이면 1/n.
- 연 자본회수비용 = Σ [P_i − S_i/(1+r)^n_i] × CRF(r,n_i).
- 연 정액 감가상각 참고값 = Σ (P_i − S_i)/n_i.
- 연 경제적 원가 = 연 자본회수비용 + 연 현금 운영비. 감가상각을 다시 가산하지 않는다.
- 정액 감가상각 포함 참고 원가 = 연 감가상각 + 연 현금 운영비. 재무제표·세법상 비용 확정 기능은 아니다.
- 시간당 원가 = 기간 원가 / (GPU 수 × 기간 시간 × 유료 가동률).
- 후보가격은 기존 매출 이익률 방식(원가 / (1−목표율)) 또는 원가 가산율 방식(원가 × (1+목표율))을 유지한다.

기간 평균 IT 전력은 유휴시간을 포함한 입력값이다. 별도 전기료 = 평균 IT kW × PUE × 기간 시간 × KRW/kWh ÷ KRW/USD. 유료 가동률을 전력에 재차 곱하지 않는다. 전기료가 운영비에 포함된 경우 별도 가산하지 않는다. 연 계산은 고정 8,760시간, 월 계산은 실제 달력 시간으로 유지한다.

자산별 결과는 서로 다른 내용연수를 연간 비용으로 환산한 비교이며, 특정 사업기간의 교체투자 현금흐름 예측이 아니다. 자산마다 종료 시점이 다르면 잔존가치를 단일 연도에 합쳐 기존 IRR/가격검토로 넘길 수 없어 자동 전달을 막는다. 현재 IRR은 중간 교체투자를 지원하지 않는다. 같은 내용연수이거나 기존 공통 모드는 기존 전달을 유지한다.

## API와 화면

BE `CostItem`에 optional `usefulLifeYears`, `residualValueUsd`를 추가한다. SCREEN_SCENARIO 자산별 모드에서는 반영된 모든 일회성 투자에 두 필드가 필요하다. 미반영·상위 포함·월/연 운영비에 자산 가정을 전송하지 않는다. 자산 잔존가치는 해당 취득비의 USD 환산액 이하여야 한다. 공통 잔존가치는 함께 전송하지 않는다. 구버전 요청은 기존 산식/응답 필드를 유지한다.

응답은 `assetSpecificLives`, `capitalAssets`, `annualStraightLineDepreciationUsd`를 추가한다. 자산별 모드의 공통 `capitalRecoveryFactor`는 null이다. 프론트는 서버가 자산별 요청을 무시하면 결과 표시를 거부한다. 주 원가/후보가/시장 비교는 Spring 결과를 사용한다.

부가 민감도만 브라우저에서 계산한다. IT 내용연수 3/5/7년 × 유료 가동률 60/75/85%이며 시설 수명, 취득비, 잔존가치, 자본비용률, 연 운영비와 평균 전력은 고정한다. 항상 연 8,760시간 기준이며 미래 시세 예측이 아니다.
