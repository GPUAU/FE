# 환율 표시와 백엔드 연결

2026-11-19 환율 표시 개선.

## 화면 동작

홈과 가격 이력에서 숨겨지던 공통 환율 패널을 표시합니다. 두 단계 접기 구조를 없애고 적용 환율, 자동/사용자 가정 구분, 공시 기준일과 출처를 바로 확인할 수 있게 했습니다. 상세 영역에는 자동환율의 수집 시각(KST), 출처 링크, 경고와 수동 환율 입력을 제공합니다.

홈의 최저/중앙값·상품 목록 및 가격 이력의 개별 관측 목록에 원화 참고값을 병기합니다. 원래 USD 정밀도로 계산하고 최종 원화만 반올림합니다. 차트와 CSV는 USD를 유지합니다. 과거 관측에 병기되는 원화는 화면의 적용 환율로 재평가한 값이며 관측 당시 원화 가격이 아닙니다.

수동 환율은 현재 페이지 메모리에만 유지하고 서버에 전송하거나 저장하지 않습니다. 자동 환율로 복귀할 수 있습니다. 자동 환율이 없으면 0원이나 예시 환율을 표시하지 않고 미확보/실패 상태와 재조회 버튼을 제공합니다. 조회 제한 시간은 8초이며, 실패 후 재조회할 수 있습니다. 기준일의 경과는 KST 달력 날짜 기준으로 4일 초과를 경고합니다.

## API와 환경변수

FE가 호출하는 주소는 `GET /api/v1/exchange-rates/latest`입니다. FE에서 한국수출입은행 API를 직접 호출하지 않습니다. 브라우저의 환율·금리 API 키 입력 및 저장 UI는 제거했습니다.

팀에서 키를 넣을 위치는 **백엔드 또는 수집기 환경**입니다. 현재 제공된 Java 수집기가 읽는 변수명은 다음과 같습니다.

```dotenv
KOREAEXIM_EXCHANGE_API_KEY=발급받은_환율_API_키
```

이 예시는 실제 키가 아닙니다. DB 접속 환경변수 `DATABASE_URL`, `DATABASE_USER`, `DATABASE_PASSWORD`도 수집기에 별도로 필요합니다. FE 저장소에 실제 .env나 키를 넣지 않습니다.

현재 Java 수집기는 `System.getenv()`로 읽습니다. **.env 파일을 생성하는 것만으로 자동 로드되지는 않습니다.** 팀의 실행 도구에서 .env를 수집기 프로세스 환경변수로 주입해야 합니다. Java 수집 작업은 백엔드의 `collectExchangeRate` Gradle 작업이며, 수집기의 DB 계정은 적재 권한이 필요합니다. 로컬 통합 서버의 조회용 read-only DB 연결을 그대로 적재용으로 사용하면 안 됩니다.

현재 latest API는 DB 조회 API입니다. 키 설정 → 실제 은행 조회 → DB 적재 성공 후, 화면의 **환율 다시 조회**로 반영합니다. 이 버튼 자체가 은행 수집을 실행하지는 않습니다. 이번 변경에는 백엔드 수집기·스케줄러·DB 수정이 포함되지 않습니다.

## API 응답 예시 — 테스트용 가상 값

```json
{
  "isSuccess": true,
  "result": {
    "status": "AVAILABLE",
    "baseCurrency": "USD",
    "quoteCurrency": "KRW",
    "rate": "1400.25",
    "referenceDate": "2026-11-19",
    "collectedAt": "2026-11-19T02:00:00Z",
    "source": {"name": "한국수출입은행", "url": "https://example.com/rates"},
    "warnings": []
  }
}
```

미적재는 `status=NOT_AVAILABLE`, `rate=null`을 사용합니다. 정상 응답이어도 환율이 양수가 아니거나 통화 방향·기준일이 유효하지 않으면 원화 환산에 사용하지 않습니다. 출처 URL은 http/https만 허용합니다.

## 검증 및 남은 확인

- 로컬에서 Node 테스트 21개 통과(기존 11개 + 환율 10개).
- 홈에서 자동환율 미확보 상태가 보이는 것 확인.
- UI에서 가정 환율 1,400 입력 후 17.802 USD가 24,923원으로 표시되고 사용자 가정 라벨로 구별되는 것 확인.
- 자동환율의 정상/미확보/잘못된 응답/실패/시간 초과/재시도와 수동 우선·복귀는 단위 테스트로 검증.
- 실제 은행 인증 및 적재는 키를 설정하지 않아 미검증.
- 가격 이력 라우팅과 재조회·반응형 화면의 최종 브라우저 검증은 로컬 연결 중단으로 완료하지 못함.

기존 `GPU_Site_Audit_20261119.md`는 변경 전 검토 기록입니다. 그 문서의 환율 패널 숨김·홈 원화 미연결 항목은 이번 변경으로 보완했으며, 다른 원가·IRR·집계·QA 오류는 이 변경의 범위에 포함하지 않았습니다.
