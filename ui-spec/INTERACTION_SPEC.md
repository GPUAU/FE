# 상호작용과 상태

| 이벤트 | 전이 / 피드백 | 예외·복구 |
|---|---|---|
| 조건 변경 | 선택 표시 → 조회/계산 → 표·차트 동기화 | 늦게 도착한 이전 응답이 최신 결과를 덮지 않게 요청 식별; 모든 화면 구현 여부 미검증 |
| 검색·정렬 | 목록만 필터, 페이지 1부터 | 검색 없음과 원본 데이터 없음 구분; 이력 검색은 차트·CSV에 미적용 |
| 페이지 | 이전/다음, 경계 비활성 | 검색 시 범위 재설정 |
| 근거 버튼 | 조회 중 → 상세 dialog | 실패 메시지; 닫기·Esc·호출 위치 복귀 확인 |
| 환율 펼침·적용 | 공시값/사용자 가정 구분, 양수만 허용, 저장 안 함 | 없거나 조회 실패 시 원화 미계산; 직접 입력 초기화 |
| 제출 | 필요한 필드 검사 → 계산 → 결과 | 오류 사유, 재입력; 민감 원가를 외부에 전송하지 않는다 |
| Agent | 연결 전 입력·전송 비활성 | 실제 연결 전 로딩·답변·근거를 임의로 생성하지 않음 |

모션은 hover/focus의 색·경계 150ms ease만 허용, 의미 없는 이동 효과 없음. reduced-motion은 전환을 끈다. 화면 리더 공지와 실패 재시도는 각 API 화면별로 검증 필요.
