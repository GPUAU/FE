# UX 구조

## 내비게이션과 화면 계약

접근 권한: 아래 일반 화면은 현재 실행본 기준, 별도 역할 인가 정책은 미확정. 관리자 화면은 기존 관리자 경로이며 서버 인가는 별도 검증 필요. 공통 진입은 메뉴 또는 링크, 이탈은 메뉴·관련 업무 링크다. 화면의 상태 열은 목표이며 미구현 상태는 QA 문서에 남긴다.

| 화면 | 목적과 주요 행동 | 우선 표시 / 배치 이유 | 정상 외 상태·복구 |
|---|---|---|---|
| 홈 | 시장 유형과 모델 선택 | 업무 바로가기 → 모델 → 기준 정보 | 로딩·실패 시 재시도 필요 |
| 가격 대시보드 | 유형·모델·계약 선택, 상품 비교 | 조건 → 선택한 상품과 가격 → 상세 근거 | 미확보와 실패 구분, 조건 변경 |
| 상품 목록·상세 | 상품 검색, 원문과 구성 확인 | 검색·사업자 필터 → 표 → 상세 | 검색 결과 없음 / 요청 실패, 검색 수정·재시도 |
| 조건별 비교 | 동일 조건·지역 제외·참고 비교 | 비교 방식 → 필터 → 표본·제외 이유 → 표 | 동일 조건 표본 없음, 참고 비교로 전환 |
| 계약 할인 | 동일 상품의 요금제별 차이 확인 | 필터 → 기준 상품 → 조건·할인 → 표 | 기준가 부족 또는 약정 가격 미확보 표시 |
| 가격 이력 | 모델·기간·사업자별 관측 조회 | 조건 → 수집 범위 → 차트 → 원본 표 | 조회 실패·재시도, 기록 없음·검색 결과 없음 구분 |
| 원가·제안가 | 사용자 가정으로 계산 | 가정 및 비용 입력 → 계산 결과와 한계 | 필수 입력 오류·미반영 비용 표시 |
| 사업성 분석 | 입력 가정의 시나리오 검토 | 투자·운영·판매 가정 → 계산 → 현금흐름 | 누락·계산 불가 표시; 실제 계약 아님 |
| Pricing Copilot | 향후 가격 질문 | 연결 상태 → 질문 예시 → 답변·근거 | API 미연결: 질문·전송 비활성. 답변 없음 |
| 데이터 품질 | 수집·검증 상태 확인 | 요약 → 모델 상태 → 실패·근거 | 수집 실패·미공개·가격 미확보 각각 구분 |
| 관심 사업자·문의 | 관심 목록과 문의 | 기존 미연결 안내 / 실제 기능 연결 시 상태 정의 | 미연결을 명시한다 |
| 관리자 DB·사용자·문의 | 운영 관리 | 현행 관리자 메뉴 | 인증·권한·오류 정책 별도 확정 필요 |
| 원본 데이터 | 공개 원본 열람 | 출처와 단위, 조회 조건 | 원본 페이지 별도 구현이며 공통 적용 범위 확인 필요 |

## 데이터 연결

조건 선택 → 현재가 API/기존 DB → 화면의 원본 정보와 단위 → 상세 근거. 이력은 Spring API의 수집 시각별 관측을 사용한다. 연결 실패는 빈 결과로 바꾸지 않는다. 내부 원가 입력은 브라우저 내 시뮬레이션이며 외부 LLM 전송을 의미하지 않는다.
