# 접근성

목표는 WCAG 2.2 AA. 자동 통과를 주장하지 않는다. 본문 텍스트 대비 4.5:1, 큰 텍스트 3:1, UI 경계·상태 3:1을 실제 조합별 측정한다. 모든 제어는 이름·상태를 제공하고 키보드 접근 가능해야 한다. :focus-visible 3px, 오프셋 2px. 폼은 label 및 오류 사유를 연결하고, 장식 아이콘은 숨긴다. 검색 결과 변경은 상태로 알린다. dialog는 제목과 닫기, Escape, 포커스 이동·복귀를 확인한다. 차트는 단위·범례·텍스트로 접근할 수 있어야 하며 색상만으로 구분하지 않는다. reduced-motion 환경에서는 움직임을 줄인다. 화면 리더, 전 색상 대비, 터치 타깃 크기, 모달 포커스 순회는 미검증이다.
