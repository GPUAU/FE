# 레이아웃 설계

아래는 구현 목표값이다. 기존 화면은 중첩 CSS로 일부 다를 수 있다. 측정값은 UI_QA_CHECKLIST를 확인한다.

| 폭 | 사이드바 | 헤더 | 좌우 패딩 | 콘텐츠 / 그리드 | 넘침 |
|---|---:|---:|---:|---|---|
| 1440 | 204px | 60px | 24px | 최대 1440px, 본문 가변·비교 2열, 간격 24px | 표 영역만 가로 스크롤 |
| 1024 | 176px 또는 축소 내비 | 60px | 24px | 가변, 필터 줄바꿈 | 표 내부 스크롤 |
| 768 | 숨김·메뉴 | 60px | 20px | 1열, 비교 영역 2열 가능 시 유지 | 표 내부 스크롤 |
| 390 | 숨김·메뉴 | 60px | 16px | 1열, 비교 상품 수직 배치 | 표 내부 스크롤 |

기본 여백 4px 배수, 섹션 간 24px. 버튼 최소 높이 40px, 입력 최소 높이 40px, 표 최소 폭 720px. 헤더 sticky top 0, 대화상자는 native dialog top layer; 드롭다운·toast는 겹침 시 화면별 확인. 목표 z-index: 콘텐츠 0, sticky 10, 헤더 30, 드롭다운 40, 모달 top layer, toast 50. 실제 기존 z-index 전수 이관은 미완료.

## 실제 측정과 차이

2026-11-18 대시보드에서 헤더 총 높이 64px로 측정되었다. 위 60px은 목표이고 기존 헤더 높이 및 테두리와 차이가 있다. 사이드바·sticky·여백은 다른 레거시 스타일의 영향을 받으므로 목표값을 전체 화면 적용 완료로 간주하지 않는다.
