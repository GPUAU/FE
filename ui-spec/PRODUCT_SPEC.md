# 제품 정의와 범위

상태: 실행본 점검 기반 설계안. 숫자·권한·데이터 출처는 실제 구현 여부를 함께 명시한다.

## 사용자와 일

| 사용자 | 결정 | 현재의 불편 | 완료 조건 |
|---|---|---|---|
| GPUaaS 프라이싱 | 경쟁 상품 대비 제안가 검토 | 모델·구성·지역·기간이 달라 가격만으로 비교하기 어려움 | 비교 조건·원본·수집 시각을 확인하고 가격 근거를 열 수 있다 |
| AI Factory 사업 담당 | 구성과 비용 가정의 사업성 검토 | 공개 가격과 내부 비용이 섞이기 쉬움 | 공개 시장정보와 사용자가 입력한 가정을 구분해 결과를 이해한다 |
| 데이터 운영자 | 수집 실패·누락 및 오래된 값 점검 | 가격 부재와 수집 실패의 의미가 다름 | 수집 상태와 원천을 확인한다 |

## 핵심 경로

대시보드에서 사업자 유형 → GPU와 계약 선택 → 상품과 환산 단가 → 상세 근거 → 이력 또는 조건별 비교. 환율 설정은 공시값과 사용자 가정을 구분한다. Agent는 연결 전 비활성 안내다.

## 제한과 충돌

- 운영 실행본은 Vue 3가 아니라 HTML/JS와 일부 React 차트로 구성되어 있다. Vue로 재작성하면 기존 기능을 바꾸므로 이번 설계는 현재 실행본에 맞추며 Vue 이전은 별도 작업이다.
- 가격 저장소가 분리되어 있다: 대시보드·목록은 기존 SQLite, 이력은 Spring/PostgreSQL. 같은 시점·같은 집합이라고 표현하지 않는다.
- 현재 인증/관리자 접근은 기존 코드 기준이며, 기업 인증·권한 운영정책은 확정되지 않았다. UI 숨김을 서버 인증의 대체로 보지 않는다.
- Agent API·실제 답변과 근거 연결은 미완료. 실제 값이 없는 모델의 0원 또는 미판매 단정 금지.
- 사용자 제공 기준: 월 단위 사업자 기준 미명시 시 730시간, 정상 가격 48시간 초과 시 최신 집계 제외, 같은 조건의 직전 확정가 30% 초과는 점검 대상으로 구분. 화면이 이를 준수하는지 전체 데이터 경로의 독립 검증은 별도 필요.
