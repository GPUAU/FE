# 페이지 와이어프레임

모든 도식은 순서와 관계를 나타내며 데이터가 없거나 미연결인 영역을 완성 기능으로 뜻하지 않는다. 화면 폭은 LAYOUT_SPEC 참조.

## 공통 / 대시보드
```
[헤더 60] 로고                                     메뉴
[사이드바 204] | 제목 / 설명
               | 관측 기준 · 환율 [펼치기]
               | 비교 유형 탭
               | GPU / 계약 필터
               | 선택 상품과 가격 차트
               | 사업자 A                 사업자 B
               | 조건 · 가격 · 근거         조건 · 가격 · 근거
```
1440px 2열, 390px 1열. 근거 버튼은 선택된 관측의 상세를 연다.

## 홈 / 상품 목록 / 조건 비교 / 할인
```
홈:        제목 → 시장 선택 → GPU 모델 → 기준/출처
목록:      제목 → 사업자·검색 → 원본·구성·가격·근거 표 → 페이지
조건비교:  제목 → 방식·조건 → 표본·제외 사유 → 비교 표 → 페이지
할인:      제목 → 상품·계약 조건 → 기준 및 약정 요금 → 원본 표
```
표는 고정 최소 폭을 두고 컨테이너에서만 가로 스크롤한다.

## 이력 / 원가 / 사업성 / Agent / 품질
```
이력:   필터 → 데이터 기간·누락 → 산점도 → 검색·정렬 표 → 페이지
원가:   가정 → 비용 입력 표 → 계산 → 한계·결과
사업성: 투자·운영·가동·판매 가정 → 시나리오 결과 → 현금흐름
Agent:  연결 상태 → 질문 예시·입력[미연결 시 비활성] → 답변·근거
품질:   상태 요약 → 대상별 확보 여부 → 수집 실패·출처
기타:   관심·문의 미연결 상태 / 관리자 인증 후 업무 / 원본 데이터 별도 목록
```
