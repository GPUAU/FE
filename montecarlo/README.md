# PM 몬테카를로 프로토타입 로컬 연동

화면: http://127.0.0.1:18091/#forecast

`몬테카를로_실행.command`로 계산 서버를 시작하고 화면을 연다.
기존 `사이트_DB_실행.command` 실행에도 계산 서버 시작을 포함했다.
기존 사이트가 꺼져 있으면 전체 실행 파일을 먼저 실행한다.

## 계산 흐름

1. PM ZIP의 가상 B300 월별 가격 18개월로 가격 범위를 계산한다.
2. 시장가 시나리오(보수 P25 / 기준 P50 / 낙관 P75 / 직접 입력)를 고른다.
3. 12개월 이후 추세(유지 / 완화 / 멈춤)를 선택한다.
4. 선택 분위 ±10%p 구간의 경로와 투자·비용·가동률 분포로 목표 IRR 기준 판매가를 계산한다.

`engine/`의 7개 파일은 PM ZIP 원본 그대로다. Python 표준 라이브러리만 사용한다.
`service.py`는 입력 검증과 JSON 응답만 추가하며 모델 산식은 변경하지 않는다.
`launch.py`는 전용 서버를 시작하거나 실행 중인 서버를 재사용한다.
계산 서버는 127.0.0.1:18096에만 바인딩하고 사이트의 로컬 출처만 CORS 허용한다.
DB를 읽거나 쓰지 않으며 외부 서비스로 입력을 전송하지 않는다.

## API (이 로컬 시연 전용)

- GET `/health`: 서비스 확인
- GET `/defaults`: PM 기본 설정과 가상 가격 이력
- POST `/forecast`: `{config}` → 12개월 P10/P25/P50/P75/P90, 근거, 설정 및 데이터 해시
- POST `/pricing`: `{config, selection: {scenario, post12_trend}}`
  또는 `{config, selection: {market_price_12m, post12_trend}}`
  → 목표 달성 확률별 필요가, 후보가격 IRR 분포, 시나리오 비교, 민감도

PM 난수 소비 순서를 보존하기 위해 예측에서도 투자 분석 기간 전체의 경로를 생성한 후
앞 12개월을 표시한다. 따라서 투자 분석 기간을 변경해도 재계산이 필요하다.
입력 변경 시 이전 결과와 다운로드를 무효화한다.
샘플 여부와 이력 파일은 요청에서 변경할 수 없다.
최대 50,000회 / 60개월, 후보가격 8개, 동시 계산 1건으로 제한한다.
프론트 입력과 결과는 메모리에만 유지하고, JSON 저장을 눌렀을 때만 파일로 내려받는다.

## 검증

```sh
python3 -m unittest discover -s montecarlo/engine -p tests.py
python3 -m unittest discover -s montecarlo -p 'test*.py'
node --test frontend/GPU_Frontend/tests/*.test.mjs
```

원본 테스트 18개, 연동 회귀·입력 검증 테스트 6개, 기존·신규 FE 테스트 58개 통과.
PM 저장 결과와 12개월 가격 분위수 및 기준·완화 판매가 분위수 일치(부동소수점 허용 오차 내).
기본값 20,000회 / 시드 20261118 / 48개월에서:

- 12개월 중앙값: 3.2176694284615026 USD/GPU-hour
- P10~P90: 2.5627947607020767 ~ 3.6346784006702606
- 기준 P50 경로 선택: 4,001개 (분위 경계의 동률 포함)
- 연 IRR 15% 달성 50% 필요가: 7.326393241985261
- 연 IRR 15% 달성 80% 필요가: 8.269642977741617

## 범위와 한계

- 가상 샘플 시연이다. 실제 수집 가격 이력과 운영 중인 Spring 예측 API에는 연결하지 않는다. 가격 검토 화면에서 원가·IRR 입력을 명시적으로 전달할 수 있으며 연결한 계산 결과를 다시 확인할 수 있다.
- 가격 이력은 18개월로 PM 권장 최소 24개월보다 짧으며 백테스트는 수행하지 않았다.
- 12개월은 예측 대상 기간일 뿐 정확도를 검증한 기간이 아니다. 13개월 이후는 명시적 추세 가정이다.
- P10~P90은 모형 안의 중앙 80% 구간이며 현실의 예측 정확도나 보장 범위가 아니다.
- 월 730시간, 세전·무차입, 독립 삼각분포, 가격탄력성 미반영 등 원본 가정을 유지한다.
- PM의 50~80% 필요 판매가 구간은 추천 하한 후보이다. 추천 범위의 최종 상한은 정의되지 않았다.
- 최종 가격 확정 및 의사결정 로그 작성 UI는 이번 연동 범위에 포함하지 않았다.
- 계산 코드와 프론트는 FE 작업 브랜치에 포함한다. Spring 백엔드 저장소는 변경하지 않는다.

## 가격 검토와 연결

`/#decision`에서 계산 후 시뮬레이션 열기를 누르면 GPU당 투자비·월 운영비·가동률·잔존가치·목표 IRR·후보가격을 전달한다. 최초 연결은 고정가, 가동 지연 0개월, 추가 비용 변동 0으로 맞춘다. 가격 이력은 B300 가상 샘플을 유지한다. 입력을 수정하면 기존 결과 및 연결을 무효화한다. 상세 변환과 제한은 `docs/FRONTEND_REVIEW_FLOW.md`를 참고한다.
