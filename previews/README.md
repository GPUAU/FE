## 디자인 미리보기

ZIP 전체를 압축 해제하고 이 폴더의 `GPU_Agent_Preview.html`을 브라우저에서 엽니다. 이미지 파일과 상대 경로가 유지되어야 하므로 HTML만 따로 이동하지 마세요.

미리보기는 현재 운영 사이트를 iframe으로 보여주고 그 위에 캐릭터 버튼 시안을 표시합니다. 인터넷과 운영 사이트 접속 권한이 필요하며, 운영 사이트 변경 시 배경 화면도 함께 바뀝니다. 브라우저의 iframe 제한에 따라 배경 사이트가 보이지 않을 수 있습니다.

버튼 클릭 시 프레임 안의 기존 Pricing Copilot 화면으로 연결합니다. 별도의 팝업 채팅창은 아직 구현하지 않았습니다. GPU 칩 캐릭터는 제안 단계이며, 이 패키지는 토끼 캐릭터 시안입니다.

## 실제 프론트 소스

`docker_erd_20261117/app/web/static/agent-launcher.js`와 `agent-launcher.css`가 플로팅 버튼 구현입니다. 메인 화면과 전체 수집 데이터 페이지에 포함되어 있습니다. 에이전트 화면에서는 버튼을 숨기고 기존 대화 상태와 질문 API를 재사용합니다.

전체 프론트 실행은 루트의 `README.md`를 참고하세요. 이 FE 패키지는 Spring 백엔드 소스·실행 DB·API 키를 포함하지 않습니다. 몬테카를로 계산 코드는 포함되어 있습니다.

`main` 병합과 운영 사이트 배포는 하지 않았습니다. JavaScript 구문 검사는 통과했으며, 플로팅 버튼의 실제 배포 화면·클릭·모바일 검증은 아직 진행하지 않았습니다.
