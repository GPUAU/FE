# GPU AU Frontend — 2026-11-19 작업본

현재 로컬 통합 사이트의 프론트 소스를 정리한 2026-11-19 작업본입니다. GPUAU/FE의 초기 README 커밋을 기반으로 별도 작업 브랜치에 반영합니다. API 연동 일부와 화면 구현을 공유하는 단계이며, 전체 명세 구현 완료본은 아닙니다.

## 포함 범위

- Signature UI와 가격 대시보드·상품 비교·계약 할인·가격 이력·원가·IRR 화면
- Spring 조회/수동환율/운영경고 연결용 프론트 어댑터
- 로컬 정적 서버 및 API 프록시 `serve.py`
- 프론트 단위 테스트과 화면 설계 문서
- `docs/GPU_Site_Audit_20261119.md`: 현재 구현과 명세 비교, 미구현/오류/문서 충돌

백엔드 구현, DB/SQL 덤프, 수집기, API 키, .env, 실행 로그는 포함하지 않습니다. 기존 화면의 일부 기능은 별도로 실행되는 Python 호환 API가 필요합니다.

## 실행

Python 3가 설치된 환경에서 이 디렉터리를 기준으로 실행합니다.

```sh
python3 serve.py
```

접속: http://127.0.0.1:18091/

| 요청 | 별도로 필요한 서버 |
|---|---|
| `/api/v1/*` | Spring: `http://127.0.0.1:18092` |
| 나머지 `/api/*`, `/public-data*` | 기존 Python 호환 API: `http://127.0.0.1:18093` |
| `/`, `/static/*` | 이 패키지의 정적 파일 |

프론트만 실행하면 화면 자산은 제공되지만 API가 필요한 데이터는 조회되지 않습니다. 현재 통합 실행본의 Python 호환 API와 Spring은 공유 PostgreSQL을 사용합니다. 이 FE 패키지는 DB에 직접 연결하지 않습니다.

## 구조

- `docker_erd_20261117/app/web/static/`: 실제 서비스 중인 정적 파일. 진입점은 `index-erd.html`
- `tests/`: Node 내장 테스트 러너 기반 테스트
- `ui-spec/`: 기존 화면 설계 자료. 실제 구현 및 최신 검토 결과와 차이가 있을 수 있음
- `docs/`: 최신 구현 검토 보고서

기존 정적 경로와 모듈 참조를 보존했습니다. 과거 화면 파일도 원 작업본에 포함된 상태로 보존했으며 모든 HTML이 현재 진입점은 아닙니다. 최종 실행 화면은 HTML/JavaScript/Chart.js 기반으로, Vue 전환 완료본이 아닙니다.

## 알려진 미완료 사항

자동환율 실데이터 미적재, Agent/몬테카를로/다중 가동률 시나리오와 시장 연계 추천 범위 미연결이 남아 있습니다. 원가·IRR은 브라우저 계산이며 서버 공통 계산 모듈로 이전하지 않았습니다. 기존 검토 보고서는 변경 전 기록입니다. 홈/비교 집계, 잔존가치 원가식·전기료, 입력 변경 시 결과 무효화, 품질 화면의 오류 격리는 이번 변경에서 보완했습니다. 상세 검증과 잔여 범위는 [기존 화면 수정 내역](docs/NON_AGENT_FIXES.md)을 참고하세요.

## 환율 표시 개선

공통 환율 패널과 홈/관측 목록의 원화 참고값을 연결했습니다. 키는 백엔드의 `.env`에서 관리하며 FE는 저장된 환율 API만 조회합니다. `.env`의 프로세스 환경 주입, 수집·적재 후 재조회 절차 및 검증 범위는 [환율 연결 안내](docs/FX_DISPLAY.md)를 참고하세요.
