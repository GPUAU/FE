# GPUAU FE — Spring 연동 작업본

HTML·JavaScript·Chart.js 프론트와 PM 몬테카를로 프로토타입 연동 코드입니다.
작업 브랜치: `feat/frontend-integration-20261119`. main 병합 전 작업본입니다.

## 실행

Python 3.10 이상에서 저장소 루트를 기준으로 실행합니다.

```sh
python3 serve.py
```

별도 터미널에서 계산 서버를 실행합니다.

```sh
python3 montecarlo/service.py
```

화면: http://127.0.0.1:18091/ · 시뮬레이션: http://127.0.0.1:18091/#forecast
시뮬레이션은 Python 표준 라이브러리와 포함된 샘플만 사용합니다.
API 명세서 화면은 PostgreSQL에 연결한 BE `main`의 `10896de` 이상을 `local` 프로필로 실행합니다.
Spring 기본 주소는 `http://127.0.0.1:18092`이며 `GPU_SPRING_BASE_URL`로 변경합니다. FE 포트는 `GPU_FE_PORT`로 바꿀 수 있습니다.
기존 리전 제외 비교와 수집 원본 등 보관 화면에는 호환 서버(기본 `http://127.0.0.1:18093`)를 사용합니다. 주소는 `GPU_LEGACY_BASE_URL`로 변경할 수 있습니다. FE와 Spring만 실행할 때는 이 값을 비워 호환 서버 연결을 끌 수 있습니다.

```sh
GPU_SPRING_BASE_URL=http://127.0.0.1:18082 GPU_LEGACY_BASE_URL='' GPU_FE_PORT=18120 python3 serve.py
```
이 FE 저장소에는 Spring 소스·DB 덤프·API 키를 포함하지 않습니다.

## 반영한 작업

- 환율 표시 및 조회 상태, 비교 가능 가격과 참고 가격 구분, 48시간 초과 자료 집계 제외 안내.
- 다운로드한 BE 기준 시장 데이터·수집 상태 표시와 가격 이력 조회 연동 보완.
- 홈·카탈로그·가격 대시보드·조건별 비교에서 Spring 카탈로그, 오퍼 목록·상세, 동일 조건 대표가격을 조회합니다. 리전 제외 비교는 보관 자료로 표시합니다.
- `#discounts`에서 상품별 온디맨드·스팟·약정과 계산 가능한 할인율을 표시합니다. `#trend`의 ‘가격·상태 변화’는 Spring의 이벤트와 이전·현재 관측 근거를 조회합니다. 변화 API의 약정 필터는 모든 약정 기간을 포함합니다.
- PM 원본 계산 엔진으로 12개월 가격 분위수 차트, 시장가 시나리오 및 이후 추세 선택.
- 목표 IRR 달성 확률별 필요 판매가, 후보가격 IRR, 민감도, 결과 JSON 저장 UI.
- 입력 변경 시 결과 무효화, 계산 중 상태, 입력 검증, 모바일 화면 보완.
- `#cost`는 API-14에서 원가·후보가와 동일 조건 비교 근거를 가져옵니다. `#bizcase`는 API-15에서 현금흐름·IRR·목표가와 선택한 시장 상한의 결과를 가져옵니다.
- `#agent`는 API-16의 공개가격 조회와 후속 질문을 사용합니다. 세션 ID는 화면을 여는 동안 메모리에만 보관합니다. ‘새 대화’는 API-17에서 세션을 삭제합니다. 만료된 세션은 알림 후 새 질문에서 다시 시작합니다.

## 남은 작업

몬테카를로는 가상 가격 18개월을 사용하는 시연입니다. 실제 데이터 적용·백테스트,
서버의 최종 추천 범위와 의사결정 기록은 후속 작업입니다. 가격 검토는 사용자가 입력한 조건으로 가동률 시나리오를 계산합니다.
상세 모델 가정은 `montecarlo/README.md`, 기존 검토 기록은 `docs/`를 참고하세요.
기존 감사 문서는 작성 당시 기록이며 현재 완료 여부는 코드와 별도 대조해야 합니다.

## 가격 검토 기능 추가

`http://127.0.0.1:18091/#decision`에서 네 가지 프론트 작업을 사용할 수 있습니다.

- 원가·가동률·IRR·PM 시뮬레이션 입력과 결과 연결. 입력 변경 시 이전 결과 무효화.
- 온디맨드·스팟·1년/3년 약정의 경쟁사 단가 차액·차이율, 계약 조건·출처·48시간 경과 표시.
- 사용자 입력 보수·기준·낙관 가동률별 매출·운영 현금흐름·IRR 비교.
- 원가/IRR 필요 하한, 사용자 상한에 따른 검토 구간과 미충족 사유 표시. JSON 저장.

최종 서버 추천가격이 아닌 사용자 조건 검토입니다. 경쟁 상품의 동일 조건 판정은 연결하지 않았으며,
PM 예측은 가상 자료입니다. 자세한 전달 규칙과 검증 기록은 `docs/FRONTEND_REVIEW_FLOW.md`를 참고하세요.
